第 1 章 · 让电脑开口说话

认识代码、学会输出，理解变量和类型，这是程序世界的字母表。

写代码是怎么回事

预计 10 分钟 · 入门 · 目标：搞懂代码是什么，并亲手让电脑打印一句话。

程序就是给电脑的指令清单

我们用中文说「去倒杯水」，电脑看不懂。要让电脑做事，就得用它认识的写法写出每一步：

print("你好")

这一行叫一条语句。print 的意思是打印出来，括号里引号包住的内容就是你要它说的话。

三条新手规则

  • 代码从上往下、一行一行执行。
  • 括号和引号都要成对出现，而且必须是英文半角符号，中文的 （ ） 会报错。
  • 行首的空格（缩进）在 Python 里不是排版，是语法。刚开始先记住：不要随便加空格。

怎么在这个平台练习

  • 每个代码框都能直接编辑，按 Ctrl + Enter 或点「运行」看结果。
  • 需要 input() 输入的程序，把要输入的内容填在代码框上方的「输入」框里，一行一个。
  • 做完练习点「检查答案」，会立刻告诉你是对是错。

注意：第一次打开页面需要联网下载 Python 引擎（约 10MB），稍等几秒，之后浏览器会缓存它。

示例：你的第一个程序

print("Hello, Python!")
print("我可以让电脑替我说话了")
print(1 + 1)

第三行没有引号，所以 Python 不把它当文字，而是真的去算 1 加 1。

让程序输出一行字：我要学会 Python

把代码框里的文字改掉就可以。

参考答案

print 的多种玩法

预计 12 分钟 · 入门 · 目标：学会一次输出多个内容，控制分隔符号和换行。

一次输出多个内容

print("姓名", "小明", "年龄", 18)

用逗号分隔，Python 会自动在它们之间补一个空格。

sep 和 end：控制细节

print("2026", "01", "01", sep="-")   # 2026-01-01
print("正在加载", end="...")
print("完成")
  • sep="-"：把逗号之间的空格换成短横线。
  • end="..."：把结尾默认的换行换成别的字符，所以下一句会接在同一行。
写法输出
print("a", "b")a b
print("a", "b", sep="")ab
print("a", end="!")a!

引号可以嵌套，但不能打架

print("他说：'你好'")    # 外面双引号，里面单引号，没问题

提示：想省心就统一用双引号写字符串，需要引号时里面用单引号。

示例：做一个简单的成绩单

print("== 期末成绩单 ==")
print("语文", 92)
print("数学", 88)
print("单号", "2026", "A", "001", sep="-")
print("总分", 92 + 88, "分")

最后一行同时用了 sep 和 end，两个参数都在引号里写。

注释与缩进

预计 10 分钟 · 入门 · 目标：学会给代码写备注，理解 Python 为什么对缩进这么严格。

注释：写给人看的话

# 后面的内容会被 Python 完全忽略，用来解释你的思路：

# 计算圆的面积
radius = 3            # 半径
area = 3.14 * radius ** 2
print(area)           # 打印结果

注释的三个用处：说明为什么这么写、临时关掉某行代码来排查问题、记录你还没搞懂的地方。

缩进：Python 的门牌号

很多语言用花括号表示「这些代码属于一起」，Python 用缩进：

if 3 > 2:
    print("3 比 2 大")
    print("这两行都属于 if")
print("这一行不属于 if，一定会执行")

规则很简单：冒号后面要缩进，同一组的缩进必须一样多。业界标准是 4 个空格，不要用 Tab。

注意：IndentationError: expected an indented block 意思是「这里该缩进却没缩进」；unexpected indent 意思是「这里不该缩进」。

示例：注释和缩进一起用

# 这个小程序判断今天要不要带伞
rain = True          # 假设今天下雨

if rain:
    print("出门记得带伞")
    print("顺便穿双防水的鞋")
print("祝你今天愉快")

前两行 print 缩进了 4 个空格，属于 if；最后一行没有缩进，所以无论如何都会执行。

变量：给数据取个名字

预计 12 分钟 · 入门 · 目标：会用变量保存数据、修改变量，掌握变量命名规则。

变量就是一个贴了标签的盒子

name = "小明"
age = 18

这里的 = 不是数学里的相等，而是赋值：把右边的值放进左边的名字里。之后提到 name，Python 就会取出里面的内容。

print(name)
name = "小红"      # 同一个名字可以装新值，旧值被覆盖
print(name)

变量名怎么起

  • 只能用字母、数字、下划线组成，而且不能以数字开头。
  • 区分大小写：age 和 Age 是两个不同的变量。
  • 不能用 Python 的保留字，比如 if、for、class、True。
  • 用有意义的名字：total_price 比 a1 好得多。

常用写法

x, y = 1, 2          # 一次给多个变量赋值
count = count + 1    # 在原来的基础上加 1

提示：报 NameError: name 'xxx' is not defined，几乎总是变量名拼错，或者还没赋值就拿来用了。变量必须先赋值才能使用。

示例：用变量讲一个会变化的故事

name = "小明"
age = 8
print(name, "今年", age, "岁")

age = age + 1      # 长大一岁
print(name, "明年", age, "岁")

age + 1 先算出 9，再放回 age 这个盒子里，所以第二句打印的是 9。

输出：杭州 今天 晴

参考答案

weather = "晴"
print(city, "今天", weather)

执行 x = 5 之后再执行 x = x + 3，x 的值是多少？

  1. 5
  2. 3
  3. 8
  4. 报错

答案：第 3 个 —— 先算右边 5 + 3 = 8，再把 8 存回 x。

数字与运算

预计 14 分钟 · 入门 · 目标：掌握四则运算、整除、取余、幂运算，分清整数和小数。

Python 是一台听话的计算器

print(7 + 2)      # 9
print(7 - 2)      # 5
print(7 * 2)      # 14
print(7 / 2)      # 3.5   除法一定得到小数
print(7 // 2)     # 3     整除：只要整数部分
print(7 % 2)      # 1     取余：只要剩下的零头
print(7 ** 2)     # 49    幂：7 的 2 次方

整数和小数

  • int 整数：3、-10、0
  • float 小数：3.14、0.5
  • 整数之间做 + - * 还是整数；只要出现 / 或小数，结果就是小数。

运算顺序

先乘除后加减，有括号先算括号，** 优先级最高。

print((1 + 2) * 3)     # 9，不是 7
print(10 % 2)          # 0 → 偶数
print(125 % 60)        # 5 → 125 分钟是 2 小时 5 分钟

提示：1 / 0 会报 ZeroDivisionError，除以 0 在数学上没有意义，Python 直接拒绝执行。

示例：把秒数换算成时分秒

total = 3725
hour = total // 3600
minute = total % 3600 // 60
second = total % 60
print(total, "秒 =", hour, "小时", minute, "分", second, "秒")

先用整除算出有几个整小时，再用取余把剩下的部分继续往下分。

字符串与 f-string

预计 14 分钟 · 入门 · 目标：会拼接字符串、量长度，并用 f-string 优雅地把变量塞进句子里。

字符串就是一段文字

引号包起来的都是字符串（str），单双引号都行，只要成对。

name = "小明"
greeting = "你好，" + name + "！"    # 加号可以拼接两段文字
print(greeting)                      # 你好，小明！
print(len(greeting))                 # 7，len 数的是字符个数

f-string：最推荐的写法

在引号前加一个 f，就能把变量直接放进花括号里：

name = "小明"
age = 8
print(f"{name}今年{age}岁，明年{age + 1}岁")
写法代码说明
加号拼接"你好" + name只能拼字符串
逗号分隔print("你好", name)自动加空格
f-stringf"你好{name}"最灵活，推荐

字符串常用小操作

s = "Python"
print(s.upper())        # PYTHON
print(s[0])             # P      下标从 0 开始数
print(s[0:3])           # Pyt    取第 0、1、2 个字符
print("Py" in s)        # True   判断是否包含
print("  hi  ".strip()) # hi     去掉两头的空格

提示：数字和字符串不能直接相加，"我" + 18 会报 TypeError。请用 f-string 或 str(18)。

示例：用 f-string 生成一句话

name = "小红"
score = 92.5
print(f"{name}的期末成绩是{score}分")
print(f"比及格线高出 {score - 60} 分")
print(f"名字长度 {len(name)}，第一个字是 {name[0]}")

花括号里不只能放变量，还能直接写算式、调用 len()。

input：让程序听你说话

预计 14 分钟 · 入门 · 目标：会用 input 接收输入，并记住它拿到的永远是字符串。

input 会暂停程序，等用户打字

name = input("你叫什么名字？")
print(f"你好，{name}！")

括号里的内容会先显示给用户看，用户按下回车后，输入的内容就装进了左边的变量。

在这个平台怎么测试 input 程序

代码框上方有一个「输入」框，把要输入的内容一行一个写进去，例如：

小明
18

程序第一次 input() 拿到 小明，第二次拿到 18。如果程序还要输入但你给的不够，就会报 EOFError。

注意：input() 拿到的永远是字符串。所以输入 18 得到的是文字 "18"，不能直接做数学运算。下一课专门讲怎么转换。

示例：会打招呼的程序

name = input("请输入你的名字：")
hobby = input("你的爱好是什么？")
print(f"{name}，原来你喜欢{hobby}，很棒！")

点「运行」，程序会依次从输入框读两行。试试把输入框的内容改成你自己的。

参考答案

数据类型与转换

预计 16 分钟 · 入门 · 目标：认识 int、float、str、bool，学会处理输入进来的数字。

四种最常见的数据类型

类型名字例子
int整数3、-7
float小数3.14、0.5
str字符串"你好"、"3"
bool真假值True、False

用 type() 可以查看类型：

print(type(3), type("3"), type(3.0), type(True))

转换函数

age = int("18")         # 字符串 → 整数
price = float("3.5")    # 字符串 → 小数
text = str(99)          # 数字 → 字符串

新手最容易踩的坑

a = input("第一个数：")   # a 是字符串 "7"
print(a + 1)              # 报错 TypeError

正确写法是把输入立刻转成数字：

a = int(input("第一个数："))
print(a + 1)

while 循环

预计 15 分钟 · 基础 · 目标：会用 while 让代码重复执行，并且不会写出死循环。

要重复一百遍？交给循环

count = 1
while count <= 5:
    print(count)
    count = count + 1
print("循环结束")

执行顺序：判断条件 → 成立就执行循环体 → 回到条件再判断，直到条件不成立。

循环的三个零件

  1. 起点：循环之前给 count 一个初值。
  2. 条件：while count <= 5。
  3. 变化：循环体里必须有让条件最终不成立的操作。

少了第 3 步就是死循环，程序永远停不下来。

提示：写死循环时一定要搭配 break 才能出来：while True: 一定要在某处跳出。

复合赋值：写得更短

短写法等于
count += 1count = count + 1
total -= 5total = total - 5
n *= 2n = n * 2

注意：这个平台的代码在浏览器里跑。万一写出死循环页面会卡住，你的代码会自动保存，刷新页面就能恢复。

示例：倒计时和求和

n = 5
while n > 0:
    print(f"倒计时 {n}")
    n -= 1
print("发射！")

total = 0
i = 1
while i <= 10:
    total += i
    i += 1
print(f"1 到 10 的和是 {total}")

两个 while 之间用空行分开，注意每个循环都有自己的变量。

break 与 continue

预计 12 分钟 · 基础 · 目标：会用 break 提前结束循环，用 continue 跳过某一次。

break：立刻跳出整个循环

for i in range(1, 100):
    if i * i > 50:
        print(i)      # 8
        break         # 找到就停，后面的数字不再检查

continue：跳过这一次，继续下一次

for i in range(1, 6):
    if i == 3:
        continue      # 3 被跳过，不打印
    print(i)
语句作用
break整个循环结束，直接执行循环后面的代码
continue只结束这一轮，马上开始下一轮

经典组合

while True:
    answer = input("输入 quit 退出：")
    if answer == "quit":
        break
    print(f"你输入了 {answer}")

提示：break 和 continue 只对它们所在的那一层循环有效，多层嵌套时要特别小心。

定义函数：给一段代码起名字

预计 14 分钟 · 基础 · 目标：会用 def 定义函数、用 return 返回结果，理解参数的作用。

为什么要写函数

同一段计算写三遍，日后改就要改三处。函数把一段逻辑打包起来，起个名字，之后随时调用：

def area(width, height):
    return width * height

print(area(3, 4))     # 12
print(area(5, 2))     # 10

读懂这几行

  • def 表示「定义函数」。
  • area 是函数名，width、height 是参数（占位用的名字）。
  • return 把结果交回给调用它的地方。
  • 调用时把真正的值传进去，这叫实参。

print 和 return 的区别（新手最容易混）

def add_print(a, b):
    print(a + b)          # 只是显示出来，外面拿不到结果

def add_return(a, b):
    return a + b          # 把结果交出去

x = add_print(1, 2)       # 屏幕上显示 3，但 x 是 None
y = add_return(1, 2)      # y 是 3
print(y + 10)             # 13

提示：一个函数没有写 return 时，它的返回值是 None（表示「什么都没有」）。

注意：小数计算会出现长尾巴，比如 100 * 1.1 得到的是 110.00000000000001（这是所有编程语言的通病）。显示时用 round(值, 2) 或 f-string 的 :.2f 处理一下就好。

函数里也可以有 if 和循环

def grade(score):
    if score >= 90:
        return "优秀"
    elif score >= 60:
        return "及格"
    return "不及格"        # 前面的条件都不满足时才会走到这里

示例：把计算打包成函数

def area(width, height):
    return width * height

def greeting(name):
    return f"你好，{name}！"

print(area(3, 4))
print(area(5, 2))
print(greeting("小明"))

定义函数时缩进的两行属于函数体；不缩进的代码才是「主程序」。

作用域：变量的活动范围

预计 12 分钟 · 基础 · 目标：理解局部变量和全局变量，能解释 UnboundLocalError 的原因。

函数里面的变量，外面看不到

def f():
    secret = 42        # 局部变量，出了函数就消失

f()
print(secret)          # 报 NameError

外面定义的变量，函数里可以读

rate = 1.1

def with_tax(price):
    return price * rate    # 能读到外面的 rate

但函数里直接改外面的变量会出问题

total = 0

def add(x):
    total = total + x    # 报 UnboundLocalError

只要函数里出现了对 total 的赋值，Python 就认为它是局部变量，而局部变量在赋值前不能读，于是报错。

正确做法有两种：

# 方法一（推荐）：用 return 把结果交出来
def add(total, x):
    return total + x

total = add(total, 5)
# 方法二：声明成全局变量（少用，容易把代码搞乱）
def add(x):
    global total
    total = total + x

提示：函数的理想状态是「给什么算出来什么，不偷偷改外面的东西」，这样的函数最好测试和维护。

示例：两种做法的对比

hits = 0

def hit_bad():
    global hits        # 直接改外面的变量
    hits += 1

def hit_good(hits):
    return hits + 1    # 把新值交出来

hit_bad()
hit_bad()
print("坏写法的结果：", hits)

hits = hit_good(hits)
print("好写法的结果：", hits)

两种写法结果一样，但第二种更容易看懂、也更好复用到别的地方。

读懂报错与 try / except

预计 15 分钟 · 基础 · 目标：会读 Python 的错误信息，并用 try/except 让程序不崩溃。

报错信息要从下往上看

Traceback (most recent call last):
  File "main.py", line 3, in <module>
    print(10 / 0)
ZeroDivisionError: division by zero
  • 最后一行：错误类型 + 原因，这是最重要的信息。
  • 上面几行：出错的位置（文件和行号）。
报错中文含义常见原因
SyntaxError语法错误括号/引号没配对、漏了冒号
IndentationError缩进错误该缩进没缩，或缩进不一致
NameError名字不存在变量名拼错、还没赋值
TypeError类型不对字符串和数字相加、参数个数不对
ValueError值不对int("abc")
IndexError下标越界列表只有 3 个元素却取第 5 个
KeyError键不存在字典里没有这个键
ZeroDivisionError除以零除数是 0

try / except：把错误兜住

try:
    n = int(input("请输入一个数字："))
    print(f"两倍是 {n * 2}")
except ValueError:
    print("这不是一个数字，请输入数字")

程序先尝试执行 try 里的代码；一旦出错，就跳到 except 里，而不是直接崩溃。

常用配套：else 和 finally

try:
    n = int("12")
except ValueError:
    print("转换失败")
else:
    print("转换成功", n)     # 没出错才执行
finally:
    print("无论如何都会执行")

提示：不要用 try 包住一大片代码。只包住你预想到会出错的那一句，出问题才容易定位。

示例：安全地读数字

text = input("请输入一个整数：")

try:
    n = int(text)
    print(f"你输入的是 {n}，两倍是 {n * 2}")
except ValueError:
    print(f"'{text}' 不是整数，请重新运行并输入数字")

文件读写

预计 15 分钟 · 基础 · 目标：会用 with open 读写文本文件，知道几种打开模式的区别。

写文件

with open("note.txt", "w", encoding="utf-8") as f:
    f.write("第一行\n")
    f.write("第二行\n")
  • "w" 表示写入，会清空原文件再写。
  • "a" 表示追加，在原内容后面接着写。
  • encoding="utf-8" 让中文正常保存，强烈建议每次都写。
  • with 会在代码块结束时自动关闭文件，不用手动 close。

读文件

with open("note.txt", "r", encoding="utf-8") as f:
    text = f.read()          # 一次性读全部
print(text)

with open("note.txt", encoding="utf-8") as f:
    for line in f:           # 一行一行读（大文件推荐）
        print(line.strip())
模式含义
"r"只读（默认），文件不存在会报错

def most_common(counts):

列表推导式：一行搞定循环

预计 14 分钟 · 进阶 · 目标：会用列表推导式生成、筛选列表，并知道什么时候该换回普通循环。

从三行变成一行

squares = []
for x in range(1, 6):
    squares.append(x * x)
print(squares)          # [1, 4, 9, 16, 25]

同样的事情，一行就能写完：

squares = [x * x for x in range(1, 6)]
print(squares)

读法：先把「要放进去的东西」写在最前面，再把 for 写在后面。

加条件筛选

evens = [x for x in range(1, 11) if x % 2 == 0]      # [2, 4, 6, 8, 10]
words = ["hi", "hello", "ok"]
long_words = [w for w in words if len(w) > 2]        # ['hello']

什么时候不要用

出现两层循环、或者条件特别绕的时候，请换回普通循环。代码是给人看的，一行写太满反而是负担。

注意：方括号最前面写的是「表达式」，不是「动作」。[print(x) for x in range(3)] 会生成一串 None，想输出就老老实实写 for 循环。

推导式家族：字典、集合与生成器

预计 14 分钟 · 进阶 · 目标：会用字典推导、集合推导和生成器表达式处理数据。

字典推导式：一边遍历一边造字典

prices = {"苹果": 5, "香蕉": 2}

print(names)             # {'小明', '小红'}

注意用的是花括号，而且没有冒号，这就是集合。

生成器表达式：省内存的懒加载

total = sum(x * x for x in range(1, 101))
print(total)             # 338350

把方括号换成圆括号就是生成器表达式：它不一次性把所有结果算出来，而是边用边算。数据量大时非常有用。

写法结果类型说明
[x for x in ...]列表全部算出来存起来
{x for x in ...}集合自动去重
{k: v for ...}字典键值对
(x for x in ...)生成器惰性求值，只能遍历一次

注意：生成器只能遍历一次。第二次再遍历就是空的，需要重新生成。

print(unique)

集合的打印顺序在 Python 里是插入顺序去重后的结果，不用纠结顺序。

参数进阶：*args 与 **kwargs

预计 15 分钟 · 进阶 · 目标：会写能接收任意个参数的函数，并会解包列表和字典来调用函数。

*args：接收任意多个位置参数

def total(*nums):
    return sum(nums)

print(total())            # 0
print(total(1, 2, 3))     # 6

函数里的 nums 是一个元组，装着你传进来的所有值。

**kwargs：接收任意多个关键字参数

def describe(**info):
    for k, v in info.items():
        print(f"{k}: {v}")

describe(name="小明", age=18)

info 是一个字典。名字 args、kwargs 只是习惯用法，重点在 * 和 **。

参数的排列顺序

def f(a, b=1, *args, key=None, **kwargs):
    ...

顺序固定为：普通参数 → 默认参数 → *args → 关键字专用参数 → **kwargs。

解包：把列表和字典摊开传进去

nums = [3, 1, 2]
print(total(*nums))        # 6，等于 total(3, 1, 2)

config = {"name": "小红", "age": 20}
describe(**config)         # 等于 describe(name="小红", age=20)

提示：写工具函数时常用这个技巧，比如日志函数的 log(msg, *tags)。

def total(*nums):

lambda 与排序的 key

预计 14 分钟 · 进阶 · 目标：会用 key 函数按规则排序，会写简单的 lambda。

sorted 的 key 参数

nums = [3, 1, 2]
print(sorted(nums))                          # [1, 2, 3]

words = ["pear", "fig", "apple"]
print(sorted(words, key=len))                # ['fig', 'pear', 'apple']

key 接收一个函数，sorted 会先把每个元素交给它算出一个「排序依据」，再按依据排序。

lambda：用完就扔的小函数

double = lambda x: x * 2        # 等价于 def double(x): return x * 2
print(double(5))

lambda 只能写一个表达式，适合当场用一次的场景，最典型就是排序：

students = [{"name": "小明", "score": 88}, {"name": "小红", "score": 95}]
students.sort(key=lambda s: s["score"], reverse=True)
print(students[0]["name"])      # 小红

多级排序：key 返回元组

# 先按分数从高到低，分数一样就按名字升序
students.sort(key=lambda s: (-s["score"], s["name"]))

加负号就是把「升序」变成「降序」。

其他常用组合

data = {"a": 3, "b": 9, "c": 5}
print(sorted(data.items(), key=lambda kv: kv[1], reverse=True))
print(max(data, key=data.get))      # 值最大的键：b

提示：key=len、key=str.lower、key=abs 这类现成函数直接用就好，不用非套 lambda。

示例：做一张排行榜

    {"name": "小明", "score": 88},
    {"name": "小红", "score": 95},
    {"name": "小刚", "score": 88},

for i, s in enumerate(students, start=1):
    print(f"{i}. {s['name']} {s['score']} 分")

enumerate(列表, start=1) 让编号从 1 开始，比手写 i + 1 更清楚。

预计 14 分钟 · 进阶 · 目标：理解类与对象的关系，会写最简单的类和实例。

用字典表示学生，问题在哪

print(student["name"])

字典能存数据，但它没有行为：想算这学生的等级，还得写一个额外的函数把字典传进去。而且字段名打错（student["nane"]）要到运行时才发现。

类：自己定义一种「数据类型」

class Student:
    def __init__(self, name, score):
        self.name = name
        self.score = score

ming = Student("小明", 88)
print(ming.name, ming.score)      # 小明 88

两个新词：

  • 类（class）：模板，比如「学生」这个概念。Student 本身就是类。
  • 对象（实例）：按模板做出来的具体东西。ming 是一个对象。

self 表示「这个对象自己」。__init__ 是初始化方法，创建对象时自动调用。

            return "及格"
        return "不及格"

继承的基本写法

        self.name = name

    def speak(self):
        return "..."

判断类型

print(isinstance(d, Animal))    # True，子类也是父类的一种

什么时候用继承

  • 用：几个类确实是「同一类东西，只有细节不同」——猫狗都是动物。
  • 别用：只是碰巧有几个方法一样——那就把公共部分抽成一个函数或模块，而不是硬套继承。

注意：继承层级不要超过两三层，超过之后读代码会非常累。组合（把对象放进属性里）往往比深层继承更好。

异常进阶：精确地兜住问题

预计 15 分钟 · 进阶 · 目标：会捕获多种异常、写 else/finally、用 raise 主动报错。

一个 try 配多个 except

try:
    age = int(input("年龄："))
    print(10 / age)
except ValueError:
    print("请输入数字")
except ZeroDivisionError:
    print("年龄不可能是 0")

Python 会从上往下匹配异常类型，只执行第一个匹配的。

一次捕获几种

try:
    do_something()
except (ValueError, TypeError) as e:
    print(f"出错了：{e}")

as e 把异常对象接出来，e 里带着原始的错误信息。

else 和 finally

try:
    n = int("12")
except ValueError:
    print("转换失败")
else:
    print("转换成功", n)      # 没出错才执行
finally:
    print("无论如何都执行")    # 收尾、关文件、解锁

raise：主动抛错

def set_age(age):
    if age < 0:
        raise ValueError(f"年龄不能是负数：{age}")
    return age

自己写函数时，遇到不该出现的输入就 raise，让错误尽早暴露，而不是让它在别的地方变成莫名其妙的 bug。

自定义异常

class NotEnoughMoneyError(Exception):
    pass

def withdraw(balance, amount):
    if amount > balance:
        raise NotEnoughMoneyError(f"余额 {balance} 不足，要取 {amount}")
    return balance - amount

注意：别写光秃秃的 except:。它会连键盘中断、程序退出信号一起吞掉，出问题极难排查。至少要写 except Exception:，最好写清楚具体类型。

示例：安全转换 + 收尾

def safe_int(text, default=0):
    try:
        return int(text)
    except ValueError:
        return default
    finally:
        print(f"（处理完 {text!r}）")

print(safe_int("42"))
print(safe_int("abc", -1))

finally 里的语句不管成功失败都会执行，所以打印了两行。

拆解成函数

def level_of(score):
    if score >= 90:
        return "优秀"
    if score >= 60:
        return "及格"
    return "不及格"

def build_rows(students):
    return [[s["name"], s["score"], level_of(s["score"])] for s in students]

def build_summary(students):
    scores = [s["score"] for s in students]
    return {
        "平均分": round(sum(scores) / len(scores), 1),
        "最高分": max(scores),
        "及格人数": sum(1 for s in students if s["score"] >= 60),
    }

with open("report.csv", "w", encoding="utf-8", newline="") as f:
    writer = csv.writer(f)
    writer.writerow(["姓名", "分数", "等级"])
    writer.writerows(build_rows(students))

with open("summary.json", "w", encoding="utf-8") as f:
    json.dump(build_summary(students), f, ensure_ascii=False, indent=2)

把题目翻译成代码的四步法

预计 15 分钟 · 进阶 · 目标：掌握拆解陌生问题的固定流程，遇到难题不再发慌。

四步法

  1. 找输入输出：给什么？要什么？先把类型写出来。
  2. 手算一个例子：用纸笔写出中间步骤，这步最容易被跳过，也最关键。
  3. 写伪代码：用中文或半成品代码把步骤写清楚。
  4. 翻译成代码并测试：先跑最简单的例子，再试边界情况。

例题：找出列表中第二大的数

第一步：输入是数字列表，输出是一个数字。

第二步：手算 [3, 1, 4, 4, 2]。

  • 去重后是 [3, 1, 4, 2]
  • 排序后是 [1, 2, 3, 4]
  • 倒数第二个是 3。

第三步伪代码：

去掉重复
从小到大排序
如果只剩一个元素 → 说明没有第二大
返回倒数第二个

第四步代码：

def second_largest(nums):
    unique = sorted(set(nums))
    if len(unique) < 2:
        return None
    return unique[-2]

边界情况：高手和新手的差距在这

  • 空列表怎么办？
  • 只有一个元素怎么办？
  • 全都是同一个数字怎么办？
  • 有重复的最大值怎么办？

写完代码前先问自己这四个问题，能挡掉大部分 bug。

提示：先写「能跑通最简单例子」的版本，再补边界处理。不要一开始就想着写最优解。

    return second

线性查找：一个一个看

简单，但数据多的时候慢。

二分查找：必须是有序的

每次砍掉一半：

def binary_search(nums, target):
    low, high = 0, len(nums) - 1
    while low <= high:
        mid = (low + high) // 2
        if nums[mid] == target:
            return mid
        if nums[mid] < target:
            low = mid + 1
        else:
            high = mid - 1
    return -1

10 亿个数据，二分查找最多比较 30 次。前提是数据已经排好序。

冒泡排序：理解排序是怎么发生的

def bubble_sort(nums):
    arr = nums[:]                      # 复制一份，不改动原列表
    for i in range(len(arr)):
        for j in range(len(arr) - 1 - i):
            if arr[j] > arr[j + 1]:
                arr[j], arr[j + 1] = arr[j + 1], arr[j]
    return arr

相邻两个比较，大的往后挪，一轮下来最大的就沉到末尾了。

实际写代码时

nums.sort()                 # 原地排序，最快
sorted(nums)                # 返回新列表

Python 内置排序是高度优化的，日常写代码直接用它们；自己写排序是为了理解原理和应付面试。

冒泡排序无慢，O(n²)

递归：函数调用自己

预计 16 分钟 · 进阶 · 目标：会写递归函数，理解终止条件的重要性。

递归的两个必备部分

def factorial(n):
    if n <= 1:              # 1. 终止条件
        return 1
    return n * factorial(n - 1)   # 2. 规模变小地调用自己

print(factorial(5))         # 120

展开看：

factorial(5)
= 5 * factorial(4)
= 5 * 4 * factorial(3)
= 5 * 4 * 3 * 2 * 1

少了终止条件就会「无限递归」，Python 会报 RecursionError: maximum recursion depth exceeded。

斐波那契：注意重复计算

def fib(n):
    if n <= 1:
        return n
    return fib(n - 1) + fib(n - 2)

这个写法好懂，但 fib(35) 会非常慢——同一个值被反复计算。改进办法是用循环，或者把算过的结果记下来（这叫记忆化）。

def fib_fast(n):
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a

递归 vs 循环

递归循环
可读性处理树、分治问题时更自然一般更直观
效率有函数调用开销，可能重复计算通常更快
风险层级太深会报错容易写出死循环

提示：能一眼看懂用循环实现的，就用循环。递归留给「问题本身就是嵌套的」场景，比如目录树、JSON 嵌套结构、汉诺塔。

算法效率直觉

预计 15 分钟 · 进阶 · 目标：会看代码估算快慢，知道嵌套循环为什么危险。

三种最常见的复杂度

复杂度名字典型代码数据量 1 万时
O(1)常数字典取值 d[key]、list[-1]1 步
O(n)线性一次 for 循环1 万步
O(n²)平方两层嵌套循环1 亿步

怎么看代码属于哪一种

total = sum(nums)                 # O(n)：内部走一遍
found_in_list = target in nums    # O(n)：从头找到尾
found_in_set = target in seen     # O(1)：集合查找是瞬间的

两层循环要小心：

# O(n²)：1 万个元素要做 1 亿次比较，慢到卡住
for x in nums:
    for y in nums:
        ...

# O(n)：用集合换速度
seen = set(nums)
for x in nums:
    if (target - x) in seen:
        ...

经验法则：嵌套循环的层数相乘。一层 O(n)，两层 O(n²)，三层 O(n³)。数据量一大就立刻爆炸。

常见优化手段

  • 把列表换成集合或字典来查找：O(n) → O(1)。
  • 提前退出：找到就 break。
  • 少重复计算：把结果存进变量。
  • 需要多次查找的数据先排序，再用二分。

def has_pair_sum(nums, target):
    seen = set()
    for n in nums:
        if (target - n) in seen:
            return True
        seen.add(n)
    return False

最常用的几个符号

符号意思例子
\d一个数字\d\d\d 匹配 123
\w字母、数字、下划线、汉字\w+
\s空白字符空格、Tab

import re

if m:

    print(m.group(1))     # 45

写测试：让代码改不坏

预计 16 分钟 · 进阶 · 目标：会用 assert 和 unittest 给自己的代码写测试。

为什么要写测试

你写了一个函数，测试通过；三天后改了别处，这个函数坏了——有测试就能立刻发现，不用等用户来投诉。

最轻量的测试：assert

def average(nums):
    return sum(nums) / len(nums)

assert average([1, 2, 3]) == 2
assert average([10]) == 10
print("全部测试通过")

assert 条件, "出错信息"：条件不成立就抛 AssertionError 并显示你的说明。

正式一点：unittest

import unittest

def average(nums):
    return sum(nums) / len(nums)

class TestAverage(unittest.TestCase):
    def test_normal(self):
        self.assertEqual(average([1, 2, 3]), 2)

    def test_one_item(self):
        self.assertEqual(average([10]), 10)

    def test_empty(self):
        with self.assertRaises(ZeroDivisionError):
            average([])

if __name__ == "__main__":
    unittest.main()

运行方式：在终端执行 python -m unittest 文件名.py。

写好测试的几个要点

  • 测试方法名用 test_ 开头，unittest 才会自动找到。
  • 一个测试只验证一件事。
  • 除了正常情况，一定要测边界：空列表、只有一个元素、负数、重复值。
  • 期望值写具体数字，别写永远成立的条件。
断言方法检查什么
assertEqual(a, b)相等
assertTrue(x)为真
assertIn(a, b)a 在 b 里
assertRaises(Error)抛出指定异常

提示：最好的写测试时机是「刚写完函数」，因为这时你最清楚它应该做什么。

示例：给函数配一组测试

def level_of(score):
    if score >= 90:
        return "优秀"
    if score >= 60:
        return "及格"
    return "不及格"

assert level_of(100) == "优秀"
assert level_of(90) == "优秀"
assert level_of(89) == "及格"
assert level_of(60) == "及格"
assert level_of(59) == "不及格"
assert level_of(0) == "不及格"

print("6 条断言全部通过")

边界值（90、60）最容易写错，所以专门测了 90 和 89、60 和 59 这两对。

contacts = {}

def add_contact(name, phone):
    contacts[name] = {"phone": phone}
    return contacts[name]

def find_contact(name):
    info = contacts.get(name)
    if info is None:
        return None
    return info["phone"]

def delete_contact(name):
    if name in contacts:
        del contacts[name]
        return True
    return False
