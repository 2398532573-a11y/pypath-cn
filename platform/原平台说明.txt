Python 零基础学习平台 · 使用说明
====================================

【怎么打开】
1. 最简单：双击桌面上的快捷方式「Python 学习平台」。
2. 或者直接双击本文件夹里的 python-learning-platform.html（用 Edge / Chrome 打开即可）。

【关于联网】
第一次点「运行」时，浏览器需要联网下载约 10MB 的 Python 引擎，大约 5~15 秒；
下载一次之后浏览器会缓存，以后运行几乎是瞬间。
如果一直显示「正在下载 Python 引擎」：
   * 先检查网络；
   * 或者双击本文件夹里的 start-learning-platform.bat，它会用本机 Python 起一个本地服务器再打开网页。
     注意：用这种方式时，先关掉之前打开的页面，避免两个页面抢进度。

【键盘快捷键】
* Ctrl + Enter：运行当前代码框
* Tab：缩进 4 个空格｜Shift + Tab：取消缩进
* 写 input() 程序时，把要输入的内容填在代码框上方的「输入」框里，一行一个

【学习数据】
进度和每个代码框里写的内容都保存在浏览器本地存储里，关掉网页再打开还在。
但清除浏览器数据、换浏览器或换电脑就会丢失，重要的代码记得自己复制出去。

【想在自己电脑上写 Python】
你的电脑已经装好 Python 3.12：打开「开始菜单」搜索 IDLE 就能用；
或者安装 VS Code，写代码更顺手。本地运行不需要联网，文件也能真正保存到硬盘。

【课程结构】
12 章 62 节课 + 66 道自动判分的练习 + 60 个术语 + 10 组语法速查表。
建议每天 40~60 分钟，六周学完第一遍（平台里「学习计划」页有详细安排）。

【八个辅助模块（左侧按钮直接进）】
* 学习计划：六周安排，标出你现在应该在第几周
* 自测考试：随机抽 20 题，交卷给分数和逐题解析
* 错题本：答错的题自动收集，支持「只练错题」
* 练习题库：65 道练习的统一入口，可以只看还没做的
* 速查表：10 组常用语法，写作时随手查
* 术语表：60 个术语，每个都标了出自哪一课
* 自由练习场：随便写，写错不影响进度
* 常见问题：环境、卡住、怎么继续学

【打卡与备份】
首页有连续打卡日历和「今日一题」。学习数据都只存在你自己的浏览器里，
可以随时「导出进度备份」存成 JSON 文件，换电脑时再「导入备份」。

【还想要纸质感觉？】
python-course-textbook.html 是一份完整的可打印讲义：62 节课的讲解、示例代码、
练习参考答案和小测验答案都在里面。用浏览器打开后按 Ctrl+P 就能打印或存成 PDF，
不需要联网，也不需要运行代码。

【图标】
app-icon.ico 是这个学习平台的图标，桌面快捷方式已经用上了它；
app-icon.png 是 512x512 的大图，可以拿去做头像、封面或二次加工。
网页标签页的图标和平台左上角的 logo 用的是同一个图标（已经内嵌进网页，不依赖外部文件）。
想换配色或调整形状：改 work/make_icon.py 里的颜色和尺寸，然后依次运行
  python work/make_icon.py
  python work/build.py
